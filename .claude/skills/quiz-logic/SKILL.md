# 出題ロジック

正は `doc/spec.md` の「5. 出題」。食い違ったら spec.md を優先し、このファイルを直す。
すべて **副作用のない純粋関数** として実装し、エクセルの読み書きや UI から切り離してテストする。
出題回数などの更新はメモリ上のセッション状態に対して行い、エクセルへはセッション終了時にまとめて反映する (`excel-io` スキル)。

## ルール

### 出題対象
- 非表示が `true` でない かつ 出題回数 < `hiddenThreshold`

### 出題順
- `head` (先頭から): No の昇順
- `fewer` (出題回数が少ない順。エクセル上の値は `1`、`head` は `0`):
  1. 出題回数 ≦ `prevHiddenThreshold` の出題対象 (No 昇順)
  2. 出題回数 ＞ `prevHiddenThreshold` の出題対象 (No 昇順)

### 開始・再開
- 開始: 並べた出題対象の先頭から、出題数ぶん
- 再開: 並べた出題対象の `resumeNo` の位置から、出題数ぶん
  - 選択中の出題順 ≠ `resumeOrder` → 先頭から (開始と同じ)
  - `resumeNo` の問題が出題対象外 → 並び順でその次の問題から
- 出題数 `0` → 開始・再開の位置から出題対象の最後まで (全件)

### 出題中
- 「次へ」(自動移動・最後の問題での終了を含む) で、移動元の問題の出題回数 +1
- 「前へ」「終了 (中断)」では +1 しない
- `resumeNo` = 次に出題すべき問題 No、`resumeOrder` = 今回の出題順
- 中断しても、その時点の `resumeNo` を保持する

### 周回数
- 出題対象のうち No が最大の問題を出題し終えたら `playCount` +1
  - 「今回のセッションの最後」ではなく「出題対象の最後」で判定
- 周回後の `resumeNo` は出題対象の先頭の No

## テストケース (最低限)
1. 非表示 `true` と、出題回数 = `hiddenThreshold` の問題が対象から外れる
2. `fewer`: prevHiddenThreshold = 3 のとき、回数 [No1:4, No2:1, No3:3, No4:5] → 順序 2, 3, 1, 4
3. 開始で出題数 > 出題対象の件数 → 出題対象の件数ぶんだけ出題
3a. 出題数 0 → 出題対象の全件を出題
4. 再開: resumeOrder 一致 → resumeNo の位置から / 不一致 → 先頭から
5. 再開: resumeNo の問題が閾値到達 → その次の問題から
6. 「前へ」で戻ってから「次へ」→ その問題が再度 +1 されること (仕様どおりか確認)
7. 出題対象の最後の問題で「次へ」→ playCount +1、resumeNo が先頭へ
8. 出題数の途中で出題対象の最後に達しない → playCount は増えない
9. 中断 → 出題回数は +1 されず、resumeNo は現在の問題

仕様から判断できないケースに当たったら、実装で決めずに質問し、決まったら spec.md に追記する。
