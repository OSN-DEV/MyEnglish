# 仕様の同期

`doc/spec.md` はデータと挙動の唯一の正。以下の手順で実装・スキルと揃える。

## 手順
1. `doc/spec.md` を読み直す (古い記憶で判断しない)
2. 今回の変更・質問に関係する章を特定する
3. 差分を分類する
   - **仕様どおり** → 何もしない
   - **仕様に書いていない挙動を実装で決めた** → ユーザーに確認し、合意した内容を spec.md に追記
   - **仕様と実装が矛盾** → どちらが正しいかユーザーに確認。実装を勝手に正としない
4. spec.md を更新したら、内容を写しているファイルも直す
   - `CLAUDE.md` の用語・ルール
   - `.claude/skills/excel-io/SKILL.md` (3 章・6 章)
   - `.claude/skills/quiz-logic/SKILL.md` (5 章)
5. 変更した章と内容を短く報告する

## 書き方
- 既存の章立て・表形式に合わせる
- 未決事項は `TBD` と書き、勝手に埋めない
- 画面レイアウトの話は `doc/ui.md` 側に書き、spec.md には持ち込まない
