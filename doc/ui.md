# アプリ仕様・UIデザイン指示書

## 1. 全体要件
- **プラットフォーム**: Tauri (デスクトップアプリ)
- **標準ウィンドウサイズ**: 800 x 600 px (リサイズ可能、標準サイズに最適化)
- **デザイン・トーン**: 明るく柔らかい配色 (パステル・ソフトモダン)。初見で直感的に操作できるUI

## 2. トップ画面 (Top Screen)
### 【レイアウト】左右2カラム構成 (左: リスト / 右: 設定)
#### ■ 左エリア: アイテム一覧 (余剰領域を全使用)
- **リスト表示要素**:
  - 表示名称 (ファイル名)
  - 実施回数 (例: 「12回実施」)
  - 削除ボタン (ゴミ箱アイコン)
- **インポートボタン**:
  - リスト右下に固定されるフローティングアクションボタン (FAB / `＋`アイコン)

#### ■ 右エリア: パネル構成
- **問題の開始条件カード**:
  - 出題数: 数値入力またはドロップダウン
  - 出題順: ラジオボタン選択 (`先頭から` / `出題数が少ない順`)
- **再生オプションカード**:
  - 自動再生: トグルスイッチ (デフォルト: ON)
  - 再生回数: 数値インプット
  - 再生後の挙動: チェックボックス (`再生後に次の問題へ自動移動する`)
  - 再生速度: セレクトボックス (`0.8` / `0.9` / `1.0` / `1.1` / `1.2` / `1.3` / `1.4` / `1.5` / デフォルト: `1.0`)
- **アクションボタン (最下部)**:
  - `開始` ボタン (メインカラー・強調)
  - `再開` ボタン (サブカラー)

---

## 3. 問題画面 (Question Screen)
### 【レイアウト】3段構成 (上: ヘッダー / 中: 学習領域 / 下: コントロール)

#### ■ ヘッダーエリア (固定高さ)
- **左側**: `終了 (戻る)` ボタン、アイテム名称
- **右側**: 進捗表示 (`今回: X / Total` 及び `アイテム内No: Y`)

#### ■ メイン学習エリア (中央スクロール可能)
- **メタ情報**: タイトル、見出し1〜3 (※見出し2・3が存在しない場合は非表示にして詰める、または「-」表記)
- **メインテキスト**:
  - 英文 (フォントサイズ大きめ、視認性重視)
  - 日本語訳 (初期状態: 表示/非表示切り替えボタン付き)
- **メモエリア**: 単語・解説情報 (カード枠で区切る)

#### ■ コントロールエリア (下部固定)
- **プレイヤーコントロール**:
  - `先頭から再生` / `再生・一時停止` / 再生速度変更
  - シークバー (再生位置スライダー + タイム表示)
  - `問題を非表示` フラグ切り替えスイッチ
- **ページネーション**:
  - `前へ` / `次へ` ボタン (押しやすいよう下部に大きく配置)
