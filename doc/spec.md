# MyEnglish 仕様書

画面レイアウトは [ui.md](ui.md) / [ui.html](ui.html) を参照。本書は **データと挙動** を定義する。

## 1. 概要
- 英文の音声を聞きながら、英文・日本語訳・メモを確認する個人用の学習アプリ (Tauri デスクトップアプリ)
- 教材はエクセルファイルで管理し、学習状態 (出題回数・非表示・再開位置・周回数) もエクセルに書き戻す

## 2. 用語
| 用語 | 意味 |
|---|---|
| アイテム | 登録した 1 つのエクセルファイル |
| 問題 | エクセルの問題シートの 1 行 |
| 出題 | 問題画面に 1 問表示すること |
| 出題対象 | 出題条件 ([5.1](#51-出題対象)) を満たす問題 |
| セッション | 開始 (または再開) 〜 終了までの一連の出題 |
| 周回 | 出題対象の最初の問題〜最後の問題まで一通り終えること |
| 閾値 | `hiddenThreshold`。出題回数がこれに達した問題は出題対象外 |

## 3. エクセルファイル構成

### 3.1 設定シート (シート名: `出力情報`)
値は **C 列の決まった行** に入れる (行番号で特定する)。C 列 1〜14 行目以外のセルはアプリでは読み書きしない。

| 行 | キー | 内容 | 必須 | 書き戻し | 空のとき | 例 |
|---|---|---|---|---|---|---|
| 1 | id | アイテムの識別子。登録済みのアイテムと重複不可 | ○ | | | `20260809182800` |
| 2 | displayName | 表示名 | ○ | | | `030. イラストでわかる！ネイティブの句動詞` |
| 3 | playCount | 周回数 | ○ | ○ | | `3` |
| 4 | hiddenThreshold | 出題対象の閾値 | ○ | | | `4` |
| 5 | prevHiddenThreshold | 前回の出題対象の閾値 (出題順の並べ替えに使用)。エクセル上で手動更新し、アプリは読み込みのみ | ○ | | | `3` |
| 6 | audioDir | 音声ファイルの格納フォルダ (絶対パス or エクセルからの相対パス) | ○ | | | `./audio` |
| 7 | resumeNo | 再開位置 (次に出題する問題 No) | | ○ | 未記録 (先頭から) | `15` |
| 8 | resumeOrder | 再開位置を記録したときの出題順 (`0` = 先頭から / `1` = 出題回数が少ない順) | | ○ | `0` | `0` |
| 9 | questionCount | 出題数 (前回値) | | ○ | `10` | `20` |
| 10 | questionOrder | 出題順 (前回値。値は resumeOrder と同じ) | | ○ | `0` | `1` |
| 11 | autoPlay | 自動再生 (前回値。`TRUE` / `FALSE`) | | ○ | `TRUE` | `TRUE` |
| 12 | repeatCount | 再生回数 (前回値) | | ○ | `1` | `2` |
| 13 | autoMove | 再生後に次の問題へ移動する (前回値。`TRUE` / `FALSE`) | | ○ | `FALSE` | `FALSE` |
| 14 | playbackSpeed | 再生速度 (前回値) | | ○ | `1.0` | `1.2` |

- 真偽値は大文字小文字を区別しない (エクセルの真偽値セル・文字列のどちらでもよい)
- 型が想定外の値はエラー (シート名・行番号・キーを表示)

### 3.2 問題シート (シート名: `Phrases`)
1 行目はヘッダ、2 行目以降が問題。

| 列 | 項目 | 必須 | 書き戻し | 備考 |
|---|---|---|---|---|
| A | No | ○ | | 1 始まりの整数。音声ファイルとの対応に使う |
| B | 見出し1 | ○ | | |
| C | 見出し2 | | | 空でも画面上の領域は確保 |
| D | 見出し3 | | | 同上 |
| E | 出題回数 | | ○ | 空 = 0 |
| F | 英文 | ○ | | |
| G | 日本語訳 | | | |
| H | メモ | | | 単語・解説 |
| I | 非表示 | | ○ | `true` で出題対象から除外 |

### 3.3 音声ファイル
- `audioDir` 内の、問題 No を 4 桁ゼロ埋めしたファイル名 (`.mp3` のみ)
  - 例: No `12` → `0012.mp3`
- ファイルが無い場合: 再生系ボタンを無効化して出題は続行

## 4. アイテム管理 (トップ画面)
- **インポート**: エクセルファイルを選択し、パスをアプリのアイテム一覧に登録する (ファイルのコピーはしない)
  - アイテム一覧 (パスのリスト) はアプリのデータフォルダに保存
  - 登録時にシート・必須列・必須キーの存在をチェックし、不正ならエラー表示
  - 登録済みのパス、または登録済みのアイテムと `id` が同じファイルは登録しない (エラー表示)
- **読み込めないアイテム**: 起動時にファイルが見つからない・読み込めない場合も、一覧から自動では外さない
  - 一覧にはファイル名とエラー内容を表示し、開始・再開はできない
  - ファイルが戻れば次回起動時から通常どおり表示される
- **表示名称**: 設定シートの `displayName`
- **回数**: 設定シートの `playCount`
- **削除**: アイテム一覧から外すだけで、エクセルファイル自体は削除しない
- エクセルは **出題開始時に毎回読み込む** (アプリ側にキャッシュしない)

## 5. 出題

### 5.1 出題対象
以下をすべて満たす問題:
- 非表示が `true` でない
- 出題回数 < `hiddenThreshold`

### 5.2 出題順
- **先頭から**: No の昇順
- **出題回数が少ない順**: 以下の順に並べる
  1. 出題回数 ≦ `prevHiddenThreshold` の出題対象 (No の昇順)
  2. 出題回数 ＞ `prevHiddenThreshold` の出題対象 (No の昇順)

### 5.3 開始・再開
- **開始**: 出題対象を出題順に並べ、先頭から出題数ぶん出題する
- **再開**: 出題対象を出題順に並べ、`resumeNo` の問題の位置から出題数ぶん出題する
  - 選択中の出題順が `resumeOrder` と異なる場合は、開始と同じく先頭から出題する
  - `resumeNo` の問題が出題対象外になっている場合 (閾値到達・非表示) は、並び順でその次にあたる問題から出題する

### 5.4 出題中
- 「次へ」で次の問題へ移動したとき、移動元の問題の出題回数を +1 する
  - 自動再生による自動移動、最後の問題での「次へ」(セッション終了) も同様に +1
  - 「前へ」「終了 (中断)」では +1 しない
- 非表示フラグを ON にした問題は、次回以降の出題対象から除外する
- 前へ / 次へ で今回のセッション内を移動。最後の問題で「次へ」→ セッション終了
- `resumeNo` は次に出題すべき問題 No、`resumeOrder` は今回の出題順で更新する
  - 出題数をこなさず中断した場合も、その時点の情報を保持し、再開でそこから続けられるようにする

### 5.5 周回数 (`playCount`)
- 出題対象のうち No が最大の問題を出題し終えたら +1 する
  - 判定するのは「今回のセッションの最後の問題」ではなく「出題対象の最後の問題」
- 周回した時点で次に出題すべき問題は出題対象の先頭になるため、`resumeNo` は先頭の問題 No になる

### 5.6 再生
- 自動再生 ON: 問題表示時に自動で再生し、`再生回数` (トップ画面の再生オプション。`playCount` とは別) 回繰り返す
  - 「再生後に次の問題へ移動」ON なら、繰り返し終了の 1 秒後に次の問題へ
- 再生速度: 0.8〜1.5 (0.1 刻み)、デフォルト 1.0
- 先頭から再生 / 再生・一時停止 / シークバーで位置変更

### 5.7 キーボードショートカット (問題画面)
| キー | 動作 |
|---|---|
| Space | 再生・一時停止 |
| n | 次へ |
| Esc | 終了 (中断) してトップ画面へ戻る |

## 6. 書き戻し
- 書き戻すタイミング: セッションが終了して TOP 画面に戻る直前に、まとめて 1 回
  - 最後の問題での「次へ」による終了、「終了 (中断)」・Esc のどちらも対象
  - セッション中の出題回数・非表示などの変更はメモリ上で保持する
  - 途中でアプリがクラッシュした場合、そのセッションの変更は失われてよい
  - 対象: 出題回数・非表示 (`Phrases`)、`playCount`・`resumeNo`・`resumeOrder`・`questionCount`〜`playbackSpeed` (`出力情報` の 3・7〜14 行目)
  - 出題・再生設定 (9〜14 行目) は、トップ画面で開始・再開したときの値を書き戻す。トップ画面で変更しても開始しなかった場合は保存しない
- 実装: Rust 側で行う。書式・数式・他シートを壊さないライブラリを選ぶ (候補: `umya-spreadsheet`。`calamine` は読み込み専用)
- エクセルで同じファイルを開いていると書き込めない場合がある (特に Windows) → エラーを表示し、ユーザーに以下のどちらかを選ばせる
    - **再試行**: もう一度書き戻す (エクセルを閉じてから押す想定)
    - **キャンセル**: 書き戻さずに TOP 画面へ戻る (そのセッションの変更は破棄)

## 7. アプリ側で保持する情報
| 情報 | 保存先 |
|---|---|
| アイテム一覧 (エクセルのパス) | アプリのデータフォルダ |

出題数・出題順・再生オプション・再生速度の前回値は、アプリ側ではなくエクセルの設定シート ([3.1](#31-設定シート-シート名-出力情報)) に保持する。

## 8. 対象外
- 教材 (エクセル) の編集機能
- 録音・発音評価
- クラウド同期・複数ユーザー
