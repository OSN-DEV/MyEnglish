# MyEnglish 仕様書

画面レイアウトは [ui.md](ui.md) / [ui.html](ui.html) を参照。本書は **データと挙動** を定義する。
`TBD` は未決事項。

## 1. 概要
- 英文の音声を聞きながら、英文・日本語訳・メモを確認する個人用の学習アプリ (Tauri デスクトップアプリ)
- 教材はエクセルファイルで管理し、学習状態 (出題回数・非表示・再開位置・周回数) もエクセルに書き戻す

## 2. 用語
| 用語 | 意味 |
|---|---|
| アイテム | 登録した 1 つのエクセルファイル |
| 問題 | エクセルの問題シートの 1 行 |
| 出題 | 問題画面に 1 問表示すること |
| セッション | 開始〜終了までの一連の出題 |
| 周回 | アイテムの最初の問題〜最後の問題まで一通り終えること |
| 閾値 | 出題回数の上限。これに達した問題は出題対象外 |

## 3. エクセルファイル構成

### 3.1 設定シート (シート名: `出力情報`)
A 列にキー、B 列に値。

| キー | 内容 | 書き戻し | 例 |
|---|---|---|---|
| 出力ファイル | 問題文のJSON(過去バージョンで使用) || 'C:¥tmp¥hoge.json'|
| 入力ファイル | 問題の実行回数(過去バージョンで使用) || 'C:¥tmp¥hoge.csv'|
| id | 問題の識別子 || '20260809182800'|
| displayName | 表示名 || '030. イラストでわかる！ネイティブの句動詞'|
| playCount | 繰り返胃回数 |◯| '3'|
| resume_no | 再開位置 (次に出題する問題 No) | ○ | `15` |
| hiddenThreshold | 出力対象の閾値 || '4'|
| prevHiddenThreshold | 前回の出力対象の閾値 || '3'|
| audio_dir | 音声ファイルの格納フォルダ (絶対パス or エクセルからの相対パス) | | `./audio` |

### 3.2 問題シート (シート名: `Phrases`)
1 行目はヘッダ、2 行目以降が問題。

| 列 | 項目 | 必須 | 書き戻し | 備考 |
|---|---|---|---|---|
| A | No | ○ | | 1 始まりの整数。音声ファイルとの対応に使う |
| B | 見出し1 | ○ | | |
| C | 見出し2 | | | 空でも画面上の領域は確保 |
| D | 見出し3 | | | 同上 |
| E | 出題回数 | | ○ | 空 = 0 |
| F | 英文 | ○ | | |
| G | 日本語訳 | | | |
| H | メモ | | | 単語・解説 |
| I | 非表示 | | ○ | `true` で出題対象から除外 |


### 3.3 音声ファイル
- `audio_dir` 内の、問題 No を 4 桁ゼロ埋めしたファイル名
  - 例: No `12` → `0012.mp3`
- 拡張子: mp3のみ
- ファイルが無い場合: 再生系ボタンを無効化して出題は続行

## 4. アイテム管理 (トップ画面)
- **インポート**: エクセルファイルを選択し、パスをアプリのアイテム一覧に登録する (ファイルのコピーはしない)
  - アイテム一覧 (パスのリスト) はアプリのデータフォルダに保存
  - 登録時にシート・必須列の存在をチェックし、不正ならエラー表示
- **表示名称**: 設定シートの`diplayName`
- **回数**: 設定シートの `playCount`
- **削除**: アイテム一覧から外すだけで、エクセルファイル自体は削除しない
- エクセルは **出題開始時に毎回読み込む** (アプリ側にキャッシュしない)

## 5. 出題

### 5.1 出題対象
以下をすべて満たす問題:
- 非表示が `true` でない
- 出題回数 < `threshold`

### 5.2 開始・再開
- **開始**: 出題対象を出題順に並べ、先頭から出題数ぶん出題する
- **再開**: `resume_no` 以降の出題対象から出題する
- 出題順
  - 先頭から: No の昇順
  - 出題数が少ない順:  `出題回数`が`prevHiddenThreshold`以下の出力対象をNoの昇順。その後`出題回数`が`prevHiddenThreshold`を超える出力対象をNoの昇順で並べる。
  出題回数の昇順、同数は No の昇順
- 再開時の出題順の扱い: 

### 5.3 出題中
- 問題を表示したら、その問題の出題回数を +1 する (タイミング: 次へ移動時)
- 非表示フラグを ON にした問題は、次回以降の出題対象から除外する
- 前へ / 次へ で今回のセッション内を移動。最後の問題で「次へ」→ 終了扱い
- 終了時に `resume_no` を次に出題すべき問題 No で更新

### 5.4 周回数 (`playCount`)
- 最後の問題 (No 最大の出題対象) まで出題し終えたら +1 する
- 今回出力した最後の問題ではなく、表示対象の最後の問題を出題し終えたら。

### 5.5 再生
- 自動再生 ON: 問題表示時に自動で再生し、`再生回数` 回繰り返す
  - 「再生後に次の問題へ移動」ON なら、繰り返し終了後に次の問題へ (間隔: 1s)
- 再生速度: 0.8〜1.5 (0.1 刻み)、デフォルト 1.0
- 先頭から再生 / 再生・一時停止 / シークバーで位置変更

## 6. 書き戻し
- 書き戻すタイミング: 出題ごと (案。途中でアプリが落ちても状態が残る)
- 注意点
  - エクセルで同じファイルを開いていると書き込めない場合がある (特に Windows) → エラーを表示して学習は続行
  - 書き戻しで書式・数式・他シートを壊さないライブラリを選ぶ (Rust 側で実装)

## 7. アプリ側で保持する情報
| 情報 | 保存先 |
|---|---|
| アイテム一覧 (エクセルのパス) | アプリのデータフォルダ |
| 出題数・出題順・再生オプション・再生速度の前回値 | アプリのデータフォルダ (共通) |
