# 教材データ一覧の手動並び替え — 実行結果

## 方針
- 行の左端のつまみ (GripVertical) をドラッグして並び替える。行クリックの選択と区別するため、つまみを掴んだときだけドラッグが始まる
- HTML5 の drag & drop は Tauri のファイルドロップ処理と競合しうるため、ポインタイベントベースの `@dnd-kit` を採用
- 並び順はアイテム一覧 (`settings.json` の `itemPaths`) の保存順そのもの。エクセルには書かない

## 変更ファイル
- `package.json`: `@dnd-kit/core` / `sortable` / `utilities` / `modifiers` を追加
- `src-tauri/src/store.rs`: `reorder_item_paths` (登録済みのパスと過不足があればエラー)、`is_same_paths` (+テスト 2 件)
- `src-tauri/src/lib.rs`: コマンド `reorder_items` を登録
- `src/repositories/ItemRepository.ts`: `reorderItems`
- `src/features/top/components/ItemRow.tsx`: `useSortable` とドラッグ用のつまみ
- `src/features/top/TopScreen.tsx`: `DndContext` / `SortableContext`。ドロップで並びを先に更新し、保存失敗なら元に戻してエラー表示。縦方向・一覧の枠内に移動を制限。キーボード (つまみにフォーカス → Space → 矢印) でも並び替え可
- `doc/spec.md` 4 / 7: 並び替えを追記
